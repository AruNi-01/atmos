# PT Design Skill

Canonical live-board skill for Atmos Agents:

`~/.atmos/skills/.system/atmos-pt-design-agent/SKILL.md`

Repo source: [`skills/atmos-pt-design-agent/`](../../../../skills/atmos-pt-design-agent/).

Read `document.ptx` (or `pt_ptx_get`), edit the XML, write it back (`pt_ptx_apply` or save the file). Do not invent Excalidraw JSON.

Do not start MCP to edit the open Prototype Design tab. Copy prompt from the board includes that skill path.

Offline `.ptd` (`document.ptx`, CLI / MCP `--file` only) is documented in the skill's [`command-reference.md`](../../../../skills/atmos-pt-design-agent/references/command-reference.md).
