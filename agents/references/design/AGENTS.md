# Atmos Design References

This directory contains detailed design guidance for Atmos agents. The root `DESIGN.md` remains the canonical entrypoint and machine-readable token source. These files carry the longer platform and component rules.

## Files

- `foundations.md`: shared visual foundations.
- `components.md`: component-level guidance.
- `web-desktop.md`: Web and Tauri Desktop shell guidance.
- `mobile.md`: native mobile guidance for iOS and Android.

## Reading Order

1. Read the root `DESIGN.md` first.
2. Read `foundations.md` for the shared visual language.
3. Read either `web-desktop.md` or `mobile.md` based on the target platform.
4. Read `components.md` when creating or changing reusable UI.
