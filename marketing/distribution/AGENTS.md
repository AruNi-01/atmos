# Marketing Distribution - AGENTS.md

> Channel planning, launch copy, and publishing notes for Atmos marketing.

---

## Scope

Use this directory for:

- X post drafts and thread variants
- Threads post drafts
- Launch calendars and checklists
- Campaign positioning notes
- Links to creative artifacts used by each channel

Do not store production source files here. Source media belongs in `marketing/creative/`.

---

## Channel Assets

Reference channel-ready assets from:

```
marketing/creative/projects/<project>/artifacts/
```

If a required asset does not exist, create or update it in the creative project first, then reference the artifact path here. Use filenames to distinguish channel, aspect ratio, and resolution when needed.

---

## Naming

- Use lowercase kebab-case for campaign folders.
- Prefer date-prefixed files for scheduled posts, e.g. `2026-06-21-launch-x.md`.
- Keep copy drafts separate by channel when formatting differs.
