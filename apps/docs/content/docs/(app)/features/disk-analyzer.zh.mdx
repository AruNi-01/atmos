磁盘分析器位于管理中心。它会扫描磁盘占用，帮你查看 Atmos 相关路径下什么占了空间，下钻大目录，并删除不再需要的文件。

默认扫描范围是 **Atmos 相关路径**（`~/.atmos`、托管项目，以及适用时的 Atmos 应用）。需要更广的整机视图时，可开启 **Scan all space**。

## 为什么重要

- 在磁盘被占满前，找到大型工作空间、runtime、缓存和构建产物。
- 日常清理优先用 Atmos 范围扫描，不必每次走完整系统扫描。
- 用列表与图表（树图 / 旭日图）下钻，再用回收站或永久删除清理。

## 打开磁盘分析器

1. 在左侧边栏打开 **Management Center**，或在全局搜索中查找 **Disk Analyzer**。
2. 打开 **Disk Analyzer**。
3. 等待默认的 Atmos 范围扫描，或重新扫描。
4. 在列表或图表中点击文件夹下钻；面包屑显示当前路径。
5. 选中项目查看体积与清理提示，确认安全后使用 **Move to trash…**。

仅在你确实需要更广扫描时开启 **Scan all space**。磁盘分析器不是专业系统清理工具；深度整机清理请使用系统侧的磁盘工具。

## 你可以做什么

| 操作 | 结果 |
|------|------|
| **Scan / Rescan** | 按当前范围重新统计占用 |
| **Scan all space** | 扩展到默认 Atmos 范围之外 |
| **Treemap / Sunburst** | 切换图表可视化 |
| **Filter / Top N** | 聚焦最大的若干项 |
| **Enter directory** | 进入文件夹 |
| **Move to trash / Delete permanently** | 确认后回收空间 |

## 使用建议

- 除非非常确定，优先移到回收站而不是永久删除。
- 当文件通过 clone 或链接共享存储时，路径合计可能大于卷已用量；卷的剩余空间才是权威容量。
- 归档旧工作空间后重新扫描，确认 **Purge Script** 与手动清理真的腾出了空间。
- 搭配 [项目与工作空间管理](/zh/workflows/project-and-workspace-manager) 的归档与 purge 流程，避免无用 worktree 堆积。
