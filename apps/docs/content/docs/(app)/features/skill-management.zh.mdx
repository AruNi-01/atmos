Skills 是给 Agent 的可复用指令。它们可以记录 Review 清单、写作规范、项目习惯或可重复工作流，让你不用每次都重新解释同一件事。

## 为什么重要

- 不用反复输入同样的 Agent 指令。
- 让团队成员之间的行为更一致。
- 只在任务需要时开启专门工作流。
- 移除过时或过于宽泛的技能。

## 你可以做什么

- 在应用中浏览可用技能。
- 一键启用或禁用技能。
- 删除不再使用的技能。
- 和 [Agent 聊天面板](/zh/features/agent-chat-panel) 搭配，处理聚焦任务。
- 在支持的 chat、review、automation 和终端 Agent 工作流中使用技能。

技能不同于 Agent 定义。内置终端 Agent、自定义 Agent 命令和保存的运行配置，请在 **Settings** -> **Code Agent** 中管理。

## 开始使用

1. 在 Atmos 中打开 **Skills**。
2. 阅读描述，理解每个技能的用途。
3. 启用符合当前项目的技能。
4. 禁用或移除会增加噪音的技能。

## Dynamic Skills（Composer 与终端）

不想离开 Welcome 或终端 AI Input，又要临时关掉某个技能？输入 `/`，打开 **Dynamic Skills**。

它和本页使用同一套启用/禁用文件。Project 开关会与这里同步；Workspace 开关只作用于当前 workplace（在 sync dirs 使用 symlink 或 copy 时尤其重要）。

完整说明见 [Dynamic Skills](/zh/how-it-works/dynamic-skills)：作用域、磁盘布局，以及如何让 Workspace symlink 同步保持 workplace 本地。

## 使用建议

- 一个技能只做一件事；把过大的技能拆小。
- 当团队流程或工具变化时，重新检查技能。
- 保持技能足够具体，让自动化或 Review Agent 不需要额外解释也能使用。
