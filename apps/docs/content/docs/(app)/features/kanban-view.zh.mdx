title: Kanban 视图
description: 在任务很多时，用看板管理工作空间状态、优先级、标签和分组。
---

Kanban 视图会把你的工作空间变成一块看板：用列表示状态，用标签表示主题，用优先级决定下一步该做什么，并用 **Groups** 按自定义聚类组织。

## 为什么重要

- 一眼看到多个 Agent 或人工任务。
- 快速发现被阻塞或停滞的工作。
- 不用额外项目管理工具，也能协调并行工作空间。
- 拖动卡片，而不是在列表里查找。
- 看板可与侧边栏分组模式对齐（状态、项目、时间、标签、优先级或 Group）。

## 可以跟踪什么

- 工作空间状态（Backlog、To Do、In Progress、In Review、Blocked、Completed、Canceled 及相关列）。
- 多个任务竞争时的优先级。
- 用来表示领域、仓库或 Agent 类型的标签。
- 看板处于分组模式时的 **Group** 成员关系——在分组列之间拖动卡片即可改归属。

## 开始使用

1. 从 Atmos 打开 **Kanban**（侧边栏，或 `⌘⇧K` 展开看板）。
2. 按状态把每个工作空间放到合适的列，或切换为项目 / 时间 / 标签 / 优先级 / Group 视图。
3. 需要时添加标签或优先级。
4. 打开卡片即可跳转到对应工作空间。
5. 任务密集时使用筛选（状态、优先级、标签、项目）与排序（最近访问、创建时间、优先级）。

## 使用建议

- 让看板回答一个问题：“我接下来该做什么？”
- 不要过度打标签；轻量的列比完美分类更有用。
- 需要先在看板上跟踪、再创建真实工作空间时，可把 GitHub Issue 导入为 **Issue Only** 卡片。
- 需要命名的项目/工作空间聚类时，先在侧边栏创建 **Groups**，再在看板上使用 **By Group**。见 [多工作空间开发](/zh/features/multi-workspace)。
