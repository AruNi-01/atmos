Canvas 是一个可视化工作板，适合那些跨多个终端、工作空间或想法的工作。你可以固定终端卡片、添加笔记、画流程、放置 GitHub 小组件，也可以在上下文太多不适合列表时，让 Agent 帮你整理画布。

画板是 `~/.atmos/canvas/` 下的**本地文档**（`.atmos.tldr` 文件）。你可以保留多个命名画板、在它们之间切换，并在编辑时依赖自动保存。

## 为什么重要

- 在同一个界面上对比多个工作空间。
- 把架构草图放在实时终端输出旁边。
- 可视化规划迁移或多仓库工作。
- 让 Agent 更新布局、笔记或图。
- 为不同线索保存独立画板（运维台、事故、架构等）。

## 可以放什么

- 来自不同工作空间或项目的终端卡片。
- 记录目标、风险或决策的便签。
- 由你或 Agent 创建的图和布局。
- 工作空间表面与小组件（文件、diff、Review、GitHub PR / Actions）。
- 工作流需要时的浏览器与截图预览。

## 文档

1. 从管理中心打开 **Canvas**。
2. 用 Canvas 工具栏中的 **Documents** 控件列出本地画板。
3. **New** 新建空画板；**Save** / **Save As** 会在 `~/.atmos/canvas/` 下命名文件。
4. 当前画板有未保存改动时，切换文档会提示保存/丢弃/取消。
5. 页面保存在同一个文档文件内——新增页面不会新建文件。

## 开始使用

1. 从 Atmos 打开 **Canvas**。
2. 固定你关心的终端或工作空间。
3. 为当前目标添加一条简短笔记。
4. 可选：为正在跟进的改动添加 GitHub PR 或 Actions 小组件。
5. 需要时让 Agent 帮你整理或记录画布。
6. 用之后还能认出来的名字保存画板。

## 使用建议

- 把 Canvas 当作工作板使用；任务完成后归档或关闭卡片。
- 和 [多工作空间开发](/zh/features/multi-workspace) 搭配，处理并行工作。
- 完整的固定与整理流程见 [在 Canvas 中构建](/zh/workflows/build-in-canvas)。
- 需要在应用外管理文件时，可备份或浏览 `~/.atmos/canvas/`。
