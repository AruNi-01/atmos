---
title: Keyboard shortcuts
description: Fast paths for navigation, terminals, workspaces, Appshots, and review.
---

Keyboard shortcuts help you move through Atmos without leaving the keyboard. Open **Settings** -> **Shortcuts** for the source of truth in your installed version.

## Global

| Action | Shortcut |
|--------|----------|
| Toggle left sidebar | `Cmd B` |
| Toggle right sidebar | `Cmd Shift B` |
| Command palette | `Cmd K` |
| Quick open file | `Cmd O` |
| Back / forward | `Cmd [` / `Cmd ]` |
| Action menu | `Cmd Shift M` |
| Usage popover | `Cmd U` |

## Workspace

| Action | Shortcut |
|--------|----------|
| New workspace overlay | `Cmd N` |
| Canvas overlay | `Cmd Shift H` |
| Kanban overlay | `Cmd Shift K` |
| Open or create workspace | `Cmd Shift Enter` |
| Overview tab | `Cmd 0` |
| Fixed terminal tab | `Cmd 1` |
| Terminal tabs 1-4 | `Cmd 2` through `Cmd 5` |

## Terminal

| Action | Shortcut |
|--------|----------|
| Split horizontal | `Cmd D` |
| Split vertical | `Cmd Shift D` |
| New tab | `Cmd T` |
| Close pane | `Cmd W` |
| Maximize panel | `Cmd Shift F` |
| Pin to Canvas | `Cmd Shift P` |
| Find | `Cmd F` |
| Toggle agent input | `Cmd G` |
| Previous / next tab | `Cmd [` / `Cmd ]` |
| Copy selection | `Cmd C` |

Many workspace and global shortcuts also work while the terminal is focused. If a shortcut is sent to the shell instead, click outside the terminal once and try again.

## Editor, review, and capture

| Action | Shortcut |
|--------|----------|
| Save current file | `Cmd S` |
| Find in editor | `Cmd F` |
| Submit prompt or commit | `Cmd Enter` |
| Multi-select diff lines | `Shift Click` |
| Capture focused desktop app as Appshot | `Left Shift + Right Shift` |
