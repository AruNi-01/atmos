---
title: 故障排查
description: 常见设置、runtime、远程、终端、移动端和 CLI 问题的修复方式。
---

先从最简单的检查开始。它们能解决大多数设置和连接问题。

## Atmos 打不开或 UI 无法连接

1. 重启 Desktop，或刷新浏览器应用。
2. 运行 `atmos runtime status`。
3. 如果 runtime 已停止或不健康，运行 `atmos runtime ensure --force-restart`。
4. 检查 `~/.atmos/runtime/logs/server.log` 中的启动错误。
5. 如果 CLI 找不到 API URL，传入 `--api-url`、设置 `ATMOS_API_URL`，或用 `atmos runtime ensure` 重新创建 `~/.atmos/runtime_manifest.json`。

本地 runtime 通常监听端口 `30303`，并写入 `~/.atmos/runtime_manifest.json`。

## CLI 返回 401 或无法鉴权

1. 如果启用了本地鉴权，设置 `--api-token`、`ATMOS_API_TOKEN` 或 `ATMOS_LOCAL_TOKEN`。
2. 如果 UI 已连接到远程电脑，确认当前 session 的 `~/.atmos/client-session.json` 存在。
3. 如果 session 过期，从 **My Computers** 重新连接。

## 终端没有响应或输出卡住

1. 停止当前卡住的命令。
2. 在同一个工作空间中打开新终端。
3. 运行 `pwd` 等小命令，确认 shell 可以工作。
4. 打开 **Terminal Manager** 检查 orphaned 或 system PTY session。
5. 如果只有移动端受影响，发送输入前先重新连接；移动端断线时不会排队发送终端输入。

## 远程电脑离线

在那台机器上：

1. 运行 `atmos computer status`。
2. 运行 `atmos runtime status`。
3. 如果 runtime 已停止，运行 `atmos runtime ensure --force-restart`。
4. 如果注册已过期，从 **Settings** -> **Atmos Computer** 生成新的注册命令。
5. 如果使用私有 Relay，确认客户端和电脑上的 Relay URL 与 secret key 一致。

## 移动端看不到或无法使用电脑

> 当前 Mobile App 处于开发阶段，暂时无法使用。

1. 从移动端设置或 Desktop/Web 生成新的注册命令。
2. 在存放仓库的电脑上运行该命令，不是在手机上运行。
3. 点击 **Refresh Computers**，选择在线电脑。
4. 如果修改了 Relay URL 或 Relay secret，打开工作空间前重新选择电脑。
5. 如果项目导入失败，确认路径存在于远程电脑上，并且是 Git 仓库。

## Appshots 无法捕获

1. 使用桌面应用。
2. 在 macOS 上授予 **Accessibility** 和 **Screen Recording** 权限。
3. 聚焦你要捕获的应用窗口。
4. 按 `Left Shift + Right Shift`。
5. 修改权限后如果仍然失败，重启 Desktop。

## Agent 输出看起来不对

检查你是否打开了正确的工作空间和项目文件夹。然后用更小、更具体的请求重新运行 Agent。

如果启动了错误的终端 Agent，打开 **Settings** -> **Code Agent**，检查启用的 Agent、命令、参数、保存的运行配置、模型、reasoning 和额外参数。

如果同时安装了 **Grok Build** 与 Cursor 相关工具，优先使用内置 **Cursor Agent**（启动 `cursor-agent`），或直接输入 `grok` / `cursor-agent`，避免裸 `agent` 命令被误标。若 Grok 用量行是空的，先运行 `grok login`。

## 磁盘已满或 Atmos 路径占用很大

1. 归档已完成的工作空间，并在已配置时运行项目的 **Purge Script**。
2. 从管理中心打开 **Disk Analyzer**，做 Atmos 范围扫描。
3. 清理时优先 **Move to trash**；删除后重新扫描。
4. 仅在你确实需要更广的整机视图时开启 **Scan all space**。

## Canvas 文档丢失或切换丢了内容

1. 画板位于 `~/.atmos/canvas/`，文件为 `*.atmos.tldr`。
2. 用 Canvas 工具栏的 **Documents** 打开命名画板。
3. 若产品提示有未保存改动，请明确选择保存或丢弃——切换会替换当前视图。
4. 确认你在有本地文件系统的 Desktop / 本地 Atmos Server 上使用。
