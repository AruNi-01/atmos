# 介绍

Atmos 是一个并发开发工作空间，把 Code Agent、终端、Git、Review 和远程机器放在同一个 UI 中管理。

它会为每个任务提供独立的 Git worktree，让长时间运行的终端会话保持在线，并让你在多个并行分支之间切换时不丢上下文。你可以把 Atmos 当作桌面应用使用，也可以在浏览器里打开、连接到 Atmos Computer，或用移动应用连接远程机器。

> 当前 Mobile App 处于开发阶段，暂时无法使用。

## 你可以做什么

- **同时运行多个任务** — 为每个功能、修复、实验或 Review 创建独立工作空间和分支。
- **让终端可恢复** — 工作空间终端能跨刷新、应用重启、连接中断和机器重启恢复。
- **使用你已经信任的 Agent** — 在工作空间 shell 中启动 Claude Code、Codex、Gemini、OpenCode、Cursor Agent 或其他终端 Agent。
- **在工作发生的地方检查结果** — 不离开工作空间就能查看文件、diff、终端输出、Agent 状态、PR、Actions 和笔记。
- **发布前先 Review** — 留下行内评论、让 Agent 修复、运行测试，然后提交或打开 PR。
- **组织并行工作** — 使用 Kanban、Canvas、标签、优先级、全局搜索和状态通知。
- **自动化重复工作** — 在正确的项目或工作空间中运行手动、定时或 GitHub 触发的自动化。
- **从其他设备工作** — 当工作需要跑在另一台机器上时，通过 Atmos Computer、Tunnel Connector 或原生移动应用连接。
