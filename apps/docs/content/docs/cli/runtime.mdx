---
title: Atmos Runtime
description: Start, stop, and check local Atmos.
---

`atmos runtime` manages the local Atmos Server on your computer. Use it when Desktop or the browser app cannot connect, when you want to start Atmos before opening the UI, or when you are preparing a machine to become an Atmos Computer.

## Common tasks

| Task | Command |
|------|---------|
| Start Atmos if it is not running | `atmos runtime ensure` |
| Start on a specific port | `atmos runtime ensure --port 30303` |
| Bind to a different host | `atmos runtime ensure --host 127.0.0.1` |
| Restart even if a runtime exists | `atmos runtime ensure --force-restart` |
| Start in the background | `atmos runtime ensure --daemon` |
| Check runtime health | `atmos runtime status` |
| Stop the local runtime | `atmos runtime stop` |
| Force stop | `atmos runtime stop --force` |

`--lan` binds to `0.0.0.0` for LAN access. The runtime manifest still points local clients at loopback.

## Local web runtime install

If the runtime binary is not installed, install the local web runtime:

```bash
curl -fsSL https://install.atmos.land/install-local-web-runtime.sh | bash
```

Useful installer flags include `--port`, `--token`, `--relay`, `--display-name`, `--daemon`, `--no-start`, `--no-open`, and `--github-source`.

## Files and logs

| Path | Purpose |
|------|---------|
| `~/.atmos/runtime/current` | Installed runtime |
| `~/.atmos/runtime_manifest.json` | Host, port, HTTP URL, and WebSocket URL for local clients |
| `~/.atmos/runtime/logs/server.log` | Runtime log |

## Tips

- Use `--json` when scripts need the raw status object.
- If `status` says the runtime is stopped, run `atmos runtime ensure --force-restart`.
- If you are using Atmos Computer, run runtime commands on the machine where your projects should live.
