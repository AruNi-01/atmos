title: Atmos Update

---

`atmos update` 会检查是否有更新的 Atmos CLI，并在可用时安装。

当应用或文档提到新的 CLI 功能，或某个命令表现和当前文档不一致时，可以使用它。

## 常见任务

| 任务 | 命令 |
|------|------|
| 只检查，不安装 | `atmos update --check` |
| 安装最新可用 CLI | `atmos update` |

## 安装位置和检查

CLI 会安装到 `~/.atmos/bin/atmos`。Desktop 和 API 也可以从 **Settings** -> **About** 检查或安装 CLI。

更新检查会优先读取 `https://install.atmos.land/cli/latest.json`。如果 manifest 暂时不可用，CLI 会回退到 GitHub release feed。

CLI 也可能在非 update 命令之后显示更新提示。设置 `ATMOS_NO_UPDATE_CHECK` 可以关闭这种机会性检查。
