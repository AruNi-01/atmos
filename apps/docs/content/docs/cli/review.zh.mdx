---
title: Atmos Review
description: 从终端参与 Review 工作流。
---

`atmos review` 让 Agent 可以从终端操作 Atmos review session。它主要用于需要读取评论、添加回复、更新状态或写总结的 Review Agent。

大多数用户会在应用里 Review 变更。当你在终端中运行编码 Agent，并希望它参与同一个 review session 时，再使用 CLI。

## 命令

| 命令 | 用途 |
|------|------|
| `session-list` | 按 `--workspace` 或 `--project` 列出 session；需要时加 `--include-archived` |
| `session-show` | 通过 `--session` 查看一个 session |
| `comment-list` | 按 `--session` 和可选 `--revision` 列出评论 |
| `comment-context` | 获取 `--comment` 周围上下文 |
| `reply-comment` | 回复评论 |
| `update-comment-status` | 设置评论状态 |
| `create-comment` | 在文件和 revision 上创建行内评论 |
| `create-agent-run` | 为 session 和 base revision 启动 review agent run |
| `summarize-run` | 写入或更新 run summary |
| `finalize-run` | 用可选 title 和 summary 完成 review run |
| `set-status` | 把 run 状态设置为 `running`、`succeeded` 或 `failed` |

## 文本输入

需要评论或总结正文的命令支持 inline、file 或 stdin 输入：

| 用途 | 参数 |
|------|------|
| 评论或回复正文 | `--body`、`--body-file`、`--body-stdin` |
| 最终 summary | `--summary`、`--summary-file`、`--summary-stdin` |

## 典型流程

1. 在 Atmos 中创建 review session。
2. 在 diff 中添加评论，或启动 Agent Review。
3. 当终端 Agent 需要 Review 上下文时，让它使用 `atmos review`。
4. 回到应用中检查更新后的 diff 和评论。

## 使用建议

- Review 时保持应用打开，这样你可以直观看到变更。
- CLI 用于 Agent 协调，不要把它当作自己阅读 diff 的替代品。
- 当另一个工具要解析输出时，优先使用 `--json`。
