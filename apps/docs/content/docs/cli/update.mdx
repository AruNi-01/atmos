---
title: Atmos Update
description: Update the CLI binary.
---

`atmos update` checks for a newer Atmos CLI and installs it when available.

Use it when the app or docs mention a new CLI feature, or when a command behaves differently from the current docs.

## Common tasks

| Task | Command |
|------|---------|
| Check without installing | `atmos update --check` |
| Install the latest available CLI | `atmos update` |

## Install location and checks

The CLI installs to `~/.atmos/bin/atmos`. Desktop and the API can also check or install the CLI from **Settings** -> **About**.

Update checks use `https://install.atmos.land/cli/latest.json` first. If that manifest is unavailable, the CLI falls back to GitHub release feeds.

The CLI may show an update hint after non-update commands. Set `ATMOS_NO_UPDATE_CHECK` to disable opportunistic checks.
