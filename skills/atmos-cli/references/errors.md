# Error codes

| Code | Meaning |
|------|---------|
| `SERVER_UNREACHABLE` | Cannot reach Atmos Server |
| `UNAUTHORIZED` | Missing/invalid token |
| `CONFIRMATION_REQUIRED` | Need `--yes` |
| `INVALID_ARGUMENT` | Bad JSON/flags |
| `UNKNOWN_ACTION` | Bad `call` action name |
| `CONTEXT_REQUIRED` | Missing project/workspace |
| `ACTION_FAILED` / `validation_error` / `not_found` | Domain failure |
| `REQUIRES_UI` | Canvas bridge / UI-only (when applicable) |
